Continuity, clearly defined

What comes with you?

The answer depends on the providers. Relay keeps the distinction explicit, so you know exactly how the next agent continues.

Claude → Claude

The same conversation.

Resume the same native Claude session under another account, with its conversation history.

Claude ↔ Codex

A new session, with context.

Any handoff involving Codex starts a new native session seeded with repository facts, git state, and bounded recent conversation context.

State continuation also applies to Codex → Codex handoffs. Provider prompt caches are not transferred. An eligible fallback is required; Relay never bypasses account limits. Read the limits →

Local by design

Your credentials stay
with your provider.

Relay opens the official provider login for each isolated profile. It never reads, copies, or stores your passwords or authentication tokens.

Runs on your machine.

No Relay-operated server. Provider traffic still goes through the Claude and Codex CLIs you use.

One owner per session.

Transfers verify that the source has stopped and the target is valid. Uncertainty stops the handoff.

Recoverable handoffs.

Each transfer is journaled. If a handoff is interrupted, Relay uses recorded evidence to decide the safe next step.
