# Third-party notices

No third-party source code has been incorporated into Agent Relay at milestone M0.

The projects studied during architecture research are listed with their licenses and exact revisions in `docs/research.md`. If implementation code is later adapted from an MIT-licensed project, its copyright and license notice, source revision, and the adapted files will be recorded here before distribution.


Agent Relay links Rust crates from crates.io (clap, serde, serde_json, sha2, fd-lock, toml, thiserror, and their transitive dependencies), each under its own permissive license; run `cargo tree` for the exact set. No third-party source has been copied into this repository.
