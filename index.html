Read the security model ↗

It stays local

Relay runs on your machine. Your installed Claude Code and Codex tools handle provider communication.

Your logins stay separate

Each profile uses its provider’s own sign in. Relay never reads, copies, or routes your credentials.

One owner at a time

Every handoff verifies the next owner. Uncertain usage or identity stops the transfer.

Before you start.

What happens to my conversation?

Claude to Claude resumes the same native conversation. Any handoff involving Codex starts a new native session with repository facts, git state, and bounded recent conversation context. Provider prompt caches are not transferred. See what continues.

Does it bypass usage limits?

No. Relay respects each provider’s limits. It can move work to another eligible account you have configured after verifying exhaustion. Unknown usage never triggers automatic handoff.

Can I choose when to switch?

Yes. Use relay switch to choose a handoff yourself. Automatic handoff is configurable, and the new owner stays active until another handoff. Read the switching guide.

What do I need installed?

Claude Code or Codex, an account for each profile you want to use, and Homebrew for the install command above. macOS is the actively validated platform. You can also build from source.
