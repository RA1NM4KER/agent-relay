Agent Relay

Keep your Claude Code session moving when one profile hits its limit.

Install

brew install RA1NM4KER/tap/agent-relay
relay setup
relay claude

How it works

  • You authenticate one or more isolated Claude accounts — Relay opens Claude's own official login, it never sees your password or token.
  • You pick a primary and a fallback order.
  • relay claude runs your session under the primary. If it genuinely runs out of quota, Relay hands the same conversation off to your next fallback automatically.

Security

Everything runs locally. Credentials stay entirely Claude-owned — Relay only launches Claude's official login/logout and never reads, copies, or stores an OAuth token, cookie, or key.
