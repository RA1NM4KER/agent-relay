What Agent Relay guarantees

01

Same session

The handoff preserves the same Claude conversation and context — not a new chat under a different account.

02

Local credentials

Claude authentication remains Claude-owned. Relay never stores your OAuth tokens, cookies, or keys.

03

One writer

Relay enforces a single-writer handoff, so two profiles never write to the same session at once.

How it works

Three steps, once.

01

relay setup

Authenticate your Claude profiles and choose a primary and fallback order.

02

relay claude

Start your normal work through Agent Relay — nothing else changes about how you use Claude Code.

03

Automatic handoff

When Relay confirms the active profile has exhausted its limit, it moves the session to the next configured profile.

Security

Runs locally. Credentials stay put.

Agent Relay coordinates handoffs between isolated Claude profiles on your own machine. It never becomes a party to your Claude credentials.

  • Runs entirely on your machineno Relay-operated server, no data leaves your machine
  • Credentials remain provider-ownedRelay launches Claude's own official login flow
  • No token storageRelay never reads, copies, or stores OAuth tokens, cookies, API keys, or passwords
  • Transactional handoffa handoff either completes cleanly or is recovered — never left half-done
  • Single-writer safetyone active writer per project, enforced, not assumed
  • Explicit profile isolationeach account lives in its own isolated configuration directory
